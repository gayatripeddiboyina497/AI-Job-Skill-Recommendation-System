# AI Job Skill Recommendation System

An interactive AI-powered web application that recommends relevant technical skills based on a user's target job role and current skills.

## Project Overview

The system analyzes job posting data to identify in-demand technical skills and provides personalized skill recommendations for different data and AI career roles.

## Supported Job Roles

- Data Analyst
- Data Scientist
- Data Engineer
- Machine Learning Engineer

## Features

- Role-based skill recommendations
- Personalized recommendations based on current skills
- Job demand analysis
- Skill demand percentage
- Skill priority levels
- Career development tips
- Interactive Streamlit interface

## Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- CSV Dataset

## Dataset

The application uses a data science job postings dataset to analyze technical skill demand across different job roles.

## How It Works

1. Select a target job role.
2. Enter your current technical skills.
3. The system compares your skills with the skills required for the selected role.
4. Missing and high-demand skills are recommended.
5. Recommendations are displayed with demand and priority information.

## Deployment

The application is deployed using Streamlit Community Cloud.
